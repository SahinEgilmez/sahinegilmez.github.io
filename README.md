## Privacy policies

- Policy directory: `https://sahinegilmez.github.io/privacy_policies/`
- Şiirhane: `https://sahinegilmez.github.io/privacy_policies/siirhane/`

To add another application, create `privacy_policies/<app-name>/index.html` and add its link to `privacy_policies/index.html`.

GitHub Pages publishes this user-site repository from the configured deployment branch. After pushing, verify under **Settings > Pages** that the source is the repository root of the intended branch (normally `main`). No build step or external dependency is required for these static files.
